# 🎮 My Game Library

Bibliothèque gaming personnelle optimisée pour ROG Ally X, PC et mobile.

## Fonctions
- Thème sombre noir / rouge / gris
- Filtres par statut
- Recherche
- Fiches détaillées
- Progression, note, temps de jeu et notes personnelles
- Pioche aléatoire
- Données personnelles sauvegardées localement dans le navigateur

Le site est prévu pour être publié avec GitHub Pages.
